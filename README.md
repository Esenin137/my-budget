💼 Мои Финансы (My Budget & IIS Analyst)

Персональный финансовый трекер, семейный бюджет, аналитик ИИС и приватный ИИ-помощник

100% локальное хранение данных • Шифрование AES-GCM-256 • Android APK & iOS PWA

🌟 О проекте

«Мои финансы» — это полноценная экосистема для управления личным и семейным капиталом, созданная без компромиссов между функциональностью и приватностью. В отличие от облачных сервисов, которые собирают историю ваших покупок, остатки по счетам и состав инвестиционного портфеля, это приложение работает полностью автономно на вашем устройстве.

Проект объединяет в себе:

Ежедневный учёт доходов и расходов с голосовым вводом, сканером QR-кодов чеков и прикреплением фотографий.

Семейный бюджет с фиксацией ежемесячных результатов, графиком динамики капитала и чек-листом регулярных платежей.

Инвестиционный аналитик ИИС и вкладов с прямой интеграцией котировок Московской биржи (ISS MOEX), расчётом налоговых вычетов (13% НДФЛ) и умным сканером активов.

Гибридного ИИ-советника, который опирается на строгую математику ваших реальных цифр, пользовательскую Базу знаний (выжимки законов и правил) и честно сообщает, если данных для ответа недостаточно.

🚀 Ключевые возможности

1. 💰 Умный бюджет и контроль целей

Гибкие периоды анализа: мгновенное переключение между срезами День / Неделя / Месяц / Год и произвольным диапазоном дат.

Безопасный дневной лимит: автоматический расчёт суммы, которую можно тратить в день до конца месяца без ухода в минус (с разделением на обязательные платежи и гибкие расходы).

Визуальные резервуары целей: интерактивные шкалы и «сосуды» наполнения для контроля лимита трат и цели накоплений на неделю, месяц и год.

Доступность для всей семьи: встроенное масштабирование шрифта (А+ / А++ / А+++) и сворачивание карточек для комфортного чтения на любом экране.

2. 🛒 Быстрый ввод расходов и чеков

Голосовой парсер на русском языке: распознаёт естественные фразы вроде «вчера кило картошки 400 рублей и аптека 1200», автоматически определяя дату, категорию и способ оплаты.

Камера и QR-сканер чеков: считывание суммы и даты напрямую из QR-кода чека с сохранением сжатого фото-подтверждения в базе.

Автоматический поиск налоговых вычетов (13% НДФЛ): система сама маркирует траты на медицину, обучение, кружки/логопедов и ипотеку, подсчитывая сумму, которую можно вернуть через ФНС.

3. 📈 Модуль ИИС, вкладов и сканер рынка

Учёт любых активов и платформ: поддержка брокерских счетов (СберИнвестиции, Т-Банк, ВТБ и др.), облигаций с купонами (ОФЗ), дивидендных акций, фондов ликвидности (SBMM / LQDT), а также обычных банковских вкладов и накопительных счетов.

Живые котировки Мосбиржи: прямое обращение к открытому шлюзу iss.moex.com без посредников и платных подписок, с автоматическим переходом в автономный режим при отсутствии сети.

Две стратегии инвестирования:

📅 «Ежемесячная зарплата» — подбор бумаг для равномерного распределения купонов и дивидендов по месяцам года.

🔥 «Максимальный процент» — сортировка по максимальной доходности к погашению и дивидендной доходности.

Учёт погрешности бюджета (до 1 000 ₽): сканер подсказывает, когда небольшая доплата поверх свободного остатка позволяет приобрести перспективный актив и ощутимо увеличить годовой доход.

4. 🤖 Честный и безопасный ИИ-Советник (RAG)

Детерминированное ядро (0 МБ нагрузки): все расчёты бюджета, подушки безопасности, вкладов и вычетов выполняются мгновенно локальным алгоритмом — без галлюцинаций, зависаний и разряда батареи.

Обучаемая База знаний: пользователь может самостоятельно загружать выжимки из финансового законодательства, налоговых правил и подключать доверенные информационные ленты (РБК, ЦБ РФ, Мосбиржа). Поиск по ключевым словам выполняется строго внутри устройства без отправки личных цифр в интернет.

Принцип честности: если в базе пользователя и загруженных материалах не хватает данных для точного ответа, ассистент не выдумывает факты, а прямо предупреждает об этом.

Уведомления и звуковые сигналы: напоминания о предстоящих купонах, сроках вкладов и регулярных платежах.

5. 👨‍👩‍👧‍👦 Семейный капитал

Объединение остатков со счетов всех членов семьи с автоматической фиксацией итога каждого месяца.

Наглядная история роста капитала и справочный трекер обязательных семейных платежей (ЖКХ, школа, ипотека, кредиты).

🛡️ Архитектура безопасности и приватности

Безопасность пользовательских данных заложена в фундамент приложения:

Zero-Server / Local-First: у проекта нет центрального сервера, который собирает ваши финансы. Вся база данных хранится локально в IndexedDB вашего устройства.

Криптографическая защита (AES-GCM-256): при установке 4-значного ПИН-кода вся база данных шифруется на устройстве с помощью Web Crypto API (PBKDF2-SHA256, 120 000 итераций).

Защищённые резервные копии: экспорт и перенос данных между устройствами доступны в виде зашифрованного паролем файла, а также в формате таблиц Excel (.xlsx) и JSON.

📱 Кроссплатформенность и сборка (Android + iOS)

Единая кодовая база проекта адаптирована сразу для двух мобильных экосистем:

Android (нативный .apk): автоматическая сборка через Capacitor и GitHub Actions (Build Android APK) — приложение устанавливается как полноценная программа с прямым доступом к локальным уведомлениям и изолированной памятью.

iOS / iPhone (PWA): поддержка полноэкранной установки «На экран Домой» через Safari с кэшированием через Service Worker для работы без интернета.
