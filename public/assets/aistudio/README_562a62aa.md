# Мои траты: как разместить и пользоваться

Приложение состоит из обычных файлов и работает без каких-либо сервисов. Данные хранятся только на устройстве.

## Как разместить (бесплатно, 5 минут)
Вариант 1, Netlify Drop: откройте app.netlify.com/drop, перетащите распакованную папку целиком. Получите ссылку вида https://...netlify.app.
Вариант 2, GitHub Pages: создайте репозиторий, загрузите все файлы, в настройках включите Pages.
Нужен именно HTTPS: без него не заработают микрофон и установка.

## Как установить на телефон
Android (Chrome): откройте ссылку, меню с тремя точками, «Установить приложение».
iPhone (Safari): откройте ссылку, «Поделиться», «На экран Домой».

## Голос
Android, Chrome: кнопка «Говорить» работает в браузере и в установленном приложении, нужно разрешить микрофон.
iPhone: в Safari кнопка обычно работает, в приложении с экрана Домой нестабильно. Запасной путь: диктовать кнопкой микрофона на клавиатуре в поле ввода, потом «Разобрать».
Распознавание речи выполняет браузер (Google или Apple), нужен интернет. Остальное работает офлайн.

## Файлы
index.html: само приложение. manifest.json и sw.js: установка и офлайн. icon-192.png, icon-512.png: значки.
